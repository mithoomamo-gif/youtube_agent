APP ICONS — GENERATED, DO NOT HAND-EDIT (Round 6, as-built)
============================================================

The icons in this directory are GENERATED by a script from artwork
the script itself draws. There is no hand-supplied source art any
more, and no step requires the Tauri CLI.

    Generator:  scripts/generate_icons.py   (Pillow only, python3)
    Regenerate: from the repo root —
                    python3 scripts/generate_icons.py
                or with the backend venv —
                    backend/.venv/bin/python scripts/generate_icons.py

What the script does:

  1. Draws the source art programmatically at 4096x4096 (4x
     supersample, for clean edges) and downsamples it with LANCZOS
     to the master:
         source-1024.png        1024 x 1024
     The art: a rounded-rectangle tile filled #0B0E13 (subtle
     vertical gradient to #151A23), a bold violet play triangle
     centred inside a thin violet ring. The violet is #6E5BFF ->
     #8B7CFF, sampled from the UI mockups (dominant accent cluster
     ~#6C59FB / #7C68FC) and identical to the frontend's accent in
     src/index.css (--color-accent / --color-accent2).
  2. Derives every shipped size FROM THE 1024 MASTER ONLY (LANCZOS):
         icon.png               512 x 512   (bundle.icon, Linux/CI)
         32x32.png              32 x 32
         128x128.png            128 x 128
         128x128@2x.png         256 x 256
         icon.ico               multi-size: 16/20/24/32/48/64/128/256
         icon.icns              16/32/64/128/256/512/1024 (Pillow ICNS)
  3. Self-checks legibility: the 16x16 render must still contain a
     saturated-violet core in its centre (the triangle), or the
     script exits non-zero instead of shipping an illegible icon.

To change the icon, edit the drawing code in
scripts/generate_icons.py and re-run it — never edit the generated
PNG/ICO/ICNS files directly, and never resize one of the small
sizes "up" into a new master.

SUPERSEDED: earlier versions of this file described a placeholder
procedure (supply approved 1024x1024 art by hand, then run
`npm run tauri icon -- src-tauri/icons/source-1024.png`). That
procedure is gone: the generated set above is the real icon set,
`tauri build` bundles icons/icon.png + icons/icon.ico as declared
in tauri.conf.json, and CI no longer needs to fail for missing icons.
