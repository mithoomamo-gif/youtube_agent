Privacy Policy — YouTube Agent

Last updated: 23 October 2026

What this app is

YouTube Agent is a desktop application that runs entirely on the user's own Windows computer. It helps the user produce and upload videos to the user's own YouTube channel. There is no YouTube Agent server, and the developer does not receive, store, or have access to the user's Google account data.

Google user data we access

When the user connects a channel, the app requests authorisation through Google OAuth to use the YouTube API Services (including the YouTube Data API) on the user's behalf — for example, to upload videos, set titles, descriptions and thumbnails, and read the channel's basic information and analytics. Authentication tokens are stored only on the user's own computer, protected by the Windows Credential Manager.

How the data is used

Google user data is used solely to provide the app's features to the user who authorised it: uploading and managing that user's own YouTube videos and displaying that channel's information inside the app. The data is not used for advertising, is not sold, and is not transferred to any third party, other than to Google/YouTube itself at the user's direction when the user uploads or manages content.

Limited Use disclosure

YouTube Agent's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Data retention and deletion

All app data, including OAuth tokens, remains on the user's computer. The user can delete it at any time by disconnecting the channel inside the app and uninstalling the app, and can revoke the app's access at any time via their Google Account's third-party access settings at myaccount.google.com/permissions, which immediately stops the app from accessing their data.

Contact

Questions about this policy can be sent to the support email address shown on the app's Google sign-in (consent) screen.
